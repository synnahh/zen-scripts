BATCH FILE COMMANDS
═══════════════════

  light1_control.bat off

  light1_control.bat color FF0000         (hex RGB)

POWERSHELL COMMANDS
═══════════════════
  .\WizLightControl.ps1 allon            → Turn all lights on
  .\WizLightControl.ps1 alloff           → Turn all lights off
  .\WizLightControl.ps1 test             → Test all lights
  .\WizLightControl.ps1 on 1             → Turn on Light 1
  .\WizLightControl.ps1 off 2            → Turn off Light 2
  .\WizLightControl.ps1 brightness 3 75  → Light 3 to 75% brightness

COLOR EXAMPLES (Hex RGB)
═════════════════════════
  FF0000 - Red
  00FF00 - Green
  0000FF - Blue
  FFFF00 - Yellow
  FF00FF - Magenta
  00FFFF - Cyan
  FFFFFF - White
